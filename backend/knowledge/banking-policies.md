\# BankAI Banking Policies



\## Savings Account



BankAI savings accounts are designed for personal banking.

Account balances are displayed in Indian Rupees (INR) unless another

currency is explicitly configured.



\## Transactions



Credit transactions increase an account balance.

Debit transactions decrease an account balance.



BankAI is a simulated banking application and does not execute real

bank transfers or real-world payments.



\## Transfers



Transfers are simulated application operations.

Users should verify the recipient account information before confirming

a simulated transfer.



\## Cards



Users can have active or inactive cards.

The application displays only the card information available in the

user's banking profile.



\## Security



Users should never share passwords, JWT tokens, API keys, PINs, or

other authentication credentials.



BankAI will not disclose internal authentication secrets or API keys.



\## AI Assistant



The BankAI AI assistant can answer questions using the user's supplied

banking data and the BankAI knowledge base.



When requested information is unavailable, the assistant should clearly

state that the information is unavailable.
